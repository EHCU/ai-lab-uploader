Privacy Policy

ai-lab uploader · Last updated 31 October 2026

ai-lab uploader is a private tool used only by its owner, Reha Yavuz, to upload videos to the owner's own YouTube channels. This page explains what data it touches.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • Permission to upload videos, captions and thumbnails to the signed-in channel (scopes youtube.upload and youtube.force-ssl).
  • The signed-in channel's name and handle, read only to confirm uploads go to the intended channel.

The tool does not read viewer data, comments, analytics, subscriber lists or any other user's information.

How data is stored

The OAuth sign-in tokens are stored only on the owner's own computer, in a file readable only by the owner. Nothing is sent to any server other than Google's. No data is sold, shared, or used for advertising.

Limited Use

ai-lab uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at Google security settings; the local tokens are then deleted.
